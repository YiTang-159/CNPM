3. web/src/components/AdminLayout.jsx: Đăng xuất từ Admin chuyển về trang chủ, không đứng lại ở màn hình từ chối quyền. Đổi nhãn liên kết thành "Xem website công khai" để làm rõ mục đích.
4. web/src/test/adminRoleNavigation.test.jsx: bổ sung kiểm thử hồi quy.

KHÔNG XÓA FILE NÀO
- Features.jsx, Demo.jsx, Pricing.jsx, About.jsx và Contact.jsx cần thiết cho website khách hàng.
- Không xóa bất kỳ route nào trong App.jsx; không sửa API, SQL Server, Docker, .env.

CÀI ĐẶT
- Sao lưu thư mục CNPM trước khi cập nhật.
- Giải nén ZIP, mở thư mục CNPM trong ZIP và chép thư mục web vào CNPM hiện có, chọn Replace khi hỏi.
- Từ Terminal tại CNPM: cd web ; npm run dev
- Nếu dev server đang chạy, Ctrl+C rồi chạy lại.
- Dùng Ctrl+Shift+R để tải lại trình duyệt.

KIỂM TRA
- Đăng nhập Admin: phải vào http://localhost:5173/#/admin/dashboard
- Admin trên các trang công khai: không còn menu khách hàng ở thanh đầu trang.
- Đăng xuất Admin: về trang công khai.
- Đăng nhập tài khoản thường: giữ nguyên Tính năng / Trải nghiệm / Bảng giá / Giới thiệu / Liên hệ.
- Muốn chạy kiểm thử từ thư mục web: npm run test -- src/test/adminRoleNavigation.test.jsx

Lưu ý: ẩn menu chỉ thay đổi trải nghiệm giao diện, không thay thế kiểm tra phân quyền trên backend.
